# CODE RUNNER: BUG CITY

เกมแพลตฟอร์ม 2D แนว Pixel Art เพื่อฝึกการสร้างเว็บไซต์ด้วย HTML, CSS และ JavaScript

## วิธีเล่น
- ใช้ปุ่ม A/D หรือปุ่มลูกศรซ้าย/ขวาเพื่อเคลื่อนที่
- กด Space หรือปุ่มลูกศรขึ้นเพื่อกระโดด
- ใช้ปุ่มโจมตีตามที่เกมแสดงบนหน้าจอ
- เก็บเหรียญ หลบอุปสรรค และตอบคำถามความรู้เพื่อผ่านด่าน

## เนื้อหาการเรียนรู้
- HTML: โครงสร้างหน้าเว็บและแท็กพื้นฐาน
- CSS: สี การจัดวาง และการตกแต่งองค์ประกอบ
- JavaScript: DOM, Events และการโต้ตอบกับผู้ใช้

## วิธีเปิดเล่นในเครื่อง
เปิดไฟล์ `index.html` ด้วย Google Chrome หรือ Microsoft Edge

## เผยแพร่ด้วย GitHub Pages
1. สร้าง GitHub repository
2. อัปโหลด `index.html` และ `README.md` ไว้ที่ root ของ repository
3. ไปที่ Settings > Pages
4. ในส่วน Build and deployment เลือก Deploy from a branch
5. เลือก branch `main` และ folder `/(root)` แล้วกด Save
6. รอให้ GitHub Pages เผยแพร่ แล้วเปิด URL ที่แสดงในหน้า Pages

> หมายเหตุ: GitHub Pages เหมาะสำหรับเผยแพร่เว็บไซต์แบบ static HTML/CSS/JavaScript หากเกมใช้ข้อมูลที่ต้องเก็บบนเซิร์ฟเวอร์หรือ API ภายนอก ต้องตั้งค่าแยกเพิ่มเติม
